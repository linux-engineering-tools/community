# Process / chemical free and open-source software (FOSS) on Linux

Steady-state thermo, kinetics, and plant-oriented simulation. Contribute **upstream**. Terms: [`../TERMS.md`](../TERMS.md).

Plant-wide **layout CAD** and many unit-operation GUIs are still gaps; describe those jobs with DEXPI / ISO 15926 / CAPE-OPEN, not vendor flowsheet clones.

| Project | Job |
|---|---|
| [DWSIM](https://dwsim.org/) | Process simulation |
| [COCO Simulator](https://www.cocosimulator.org/) | CAPE-OPEN flowsheeting |
| [Cantera](https://cantera.org/) | Chemical kinetics / thermodynamics |
| [OpenFOAM](https://openfoam.org/) | Reacting / process CFD |

GUI vs TUI: Cantera and OpenFOAM are library/TUI. DWSIM has a GUI; prefer its documented file formats for LET tests.
