# Security

Report vulnerabilities in LET repositories privately. Do not open a public issue.

Use GitHub’s **Private vulnerability reporting** on the affected repository (Security tab → Advisories → Report a vulnerability).

Include:

- Repository and commit or tag
- What an attacker can do
- Reproduction steps or a proof of concept that does not include proprietary third-party material

If private reporting is not yet enabled on a repo, email the org owners listed on https://github.com/linux-engineering-tools.

This community repository is documentation. Tool repos should enable private vulnerability reporting when they are created.
